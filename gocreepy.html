Google API Endpoint Builder

A simple utility to find your IDs and construct valid API URLs.

1. Get Your Details

How to find your Google ID (Gaia ID):

  1. Visit the People API Explorer.
  2. In the `resourceName` field, enter people/me.
  3. (Important) In the `personFields` field, enter metadata,names.
  4. Click "Execute", authorize your account, and find the 21-digit number next to `"id":` in the results.

How to get an API Key:

  1. Go to the Google Cloud Credentials page.
  2. Create or select a project.
  3. Click + CREATE CREDENTIALS and choose API key. Copy the key.
