How to Use These Effects in Gmail

  1. Copy the HTML from any effect you like
  2. In Gmail, start a new email
  3. Click on the "Formatting options" button (A in the toolbar)
  4. Select "Insert HTML" (you may need to click on the three dots "..." to find this option)
  5. Paste the HTML code into the dialog box
  6. Click "Insert" to apply the effect

Note: Some effects might render slightly differently depending on the email client your recipient uses. These examples are designed to work best with Gmail's rendering engine.
