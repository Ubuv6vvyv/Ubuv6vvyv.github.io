6. Audio Selection Deterrent

Try to select the text below. A subtle audio tone will play. The more text you select, the higher-pitched and more grating the tone becomes as a deterrent.

This is an auditory defense mechanism. When a user begins to select this text, a low-frequency square wave tone is generated using the Web Audio API.
