Image Processing Guide

Document / Text Processing

1. Start with Adaptive Threshold method 2. Adjust brightness if the text is too light/dark (+20 to +40 for dark images) 3. Fine-tune Adaptive Sensitivity: - Increase (2-6) for bold text - Decrease (-2 to -6) for thin text 4. Add slight Edge Enhancement (10-20) if text edges are fuzzy

Technical Drawings / Blueprints

1. Use Regular Threshold method 2. Start with high contrast (+30 to +50) 3. Adjust Threshold Level to capture lines (around 127) 4. Apply Edge Enhancement (20-40) to sharpen lines 5. Invert if needed (usually for blueprints)

Handwritten Notes

1. Use Adaptive Threshold method 2. Increase brightness slightly (+10 to +30) 3. Set Adaptive Sensitivity low (-4 to 0) 4. Add minimal Edge Enhancement (5-15) 5. Adjust contrast if needed (+20 to +40)

Understanding the Tools

Regular vs Adaptive Threshold: Regular works best with high-contrast images and consistent lighting. Adaptive excels with varying lighting conditions and subtle details.

Brightness/Contrast: Use brightness first to make the important details visible, then contrast to increase separation between light and dark areas.

Edge Enhancement: Helps clarify boundaries between objects. Use sparingly (10-30) for most cases, higher (40-70) for technical drawings.

Adaptive Sensitivity: Higher values (+) make the threshold more aggressive, lower values (-) are more forgiving. Start at 2 and adjust based on results.
