1. Image & Scan Enhancement (ImageMagick)

Task / Goal Single File Command Batch Folder Loop (Copy/Paste)
IMRecipe A: "Valuation Pro" Fixes skew, cleans noise, mild contrast, vivid color. Best for mixed content. magick -density 200 "IN.pdf" -deskew 40% -despeckle -sigmoidal-contrast 10x50% -modulate 100,130 -unsharp 0x1.5 -quality 90 "OUT.jpg" for f in *.pdf; do magick -density 200 "$f" -deskew 40% -despeckle -sigmoidal-contrast 10x50% -modulate 100,130 -unsharp 0x1.5 -quality 90 "${f%.pdf}.jpg"; done
IMRecipe B: "Strict Text" Forces dark grays to black, light grays to white. Best for faded documents. magick -density 200 "IN.pdf" -deskew 40% -despeckle -black-threshold 50% -white-threshold 85% -unsharp 0x1.5 -quality 85 "OUT.jpg" for f in *.pdf; do magick -density 200 "$f" -deskew 40% -despeckle -black-threshold 50% -white-threshold 85% -unsharp 0x1.5 -quality 85 "${f%.pdf}.jpg"; done
IMRecipe C: "Grayscale Saver" Converts to B&W to minimize file size. magick -density 150 "IN.pdf" -colorspace Gray -deskew 40% -contrast-stretch 1% -quality 80 "OUT.jpg" for f in *.pdf; do magick -density 150 "$f" -colorspace Gray -deskew 40% -contrast-stretch 1% -quality 80 "${f%.pdf}.jpg"; done
IMFormat: Lossless PNG For intermediate editing without quality loss. magick -density 300 "IN.pdf" "OUT.png" for f in *.pdf; do magick -density 300 "$f" "${f%.pdf}.png"; done
IMFormat: WebP (Modern) Google's format. 30-50% smaller than JPG at same quality. magick "IN.jpg" -quality 85 "OUT.webp" for f in *.jpg; do magick "$f" -quality 85 "${f%.jpg}.webp"; done

2. PDF Manipulation (Ghostscript / QPDF)

Task / Goal Single File / List Batch Folder Loop
GSMerge PDFs (Simple) Joins files sequentially. gs -dNOPAUSE -sDEVICE=pdfwrite -sOutputFile="MERGED.pdf" -dBATCH "A.pdf" "B.pdf" gs -dNOPAUSE -sDEVICE=pdfwrite -sOutputFile="MERGED_ALL.pdf" -dBATCH *.pdf
GSCompress: Ebook (150dpi) Good balance of size/quality. gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook -dNOPAUSE -dBATCH -sOutputFile="small.pdf" "BIG.pdf" mkdir small; for f in *.pdf; do gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook -dNOPAUSE -dBATCH -sOutputFile="small/$f" "$f"; done
GSCompress: Screen (72dpi) Smallest size, low quality. gs -sDEVICE=pdfwrite -dPDFSETTINGS=/screen -dNOPAUSE -dBATCH -sOutputFile="tiny.pdf" "BIG.pdf" mkdir tiny; for f in *.pdf; do gs -sDEVICE=pdfwrite -dPDFSETTINGS=/screen -dNOPAUSE -dBATCH -sOutputFile="tiny/$f" "$f"; done
GSSplit into Pages Extracts every page as a separate file. gs -sDEVICE=pdfwrite -o "page-%d.pdf" "IN.pdf" for f in *.pdf; do mkdir "${f%.pdf}_p"; gs -sDEVICE=pdfwrite -o "${f%.pdf}_p/p-%d.pdf" "$f"; done
QPDFUnlock / Decrypt Removes password (if known). qpdf --decrypt --password=PASS "LOCKED.pdf" "OPEN.pdf" # Batch assumes same password
for f in *.pdf; do qpdf --decrypt --password=PASS "$f" "unlocked_$f"; done
QPDFLinearize (Repair) Fixes web viewing & structural errors. qpdf --linearize --replace-input "BROKEN.pdf" for f in *.pdf; do qpdf --linearize --replace-input "$f"; done

3. Data Extraction (Poppler / Utils)

Task / Goal Single File Command Batch Folder Loop
POPExtract Raw Images Saves images embedded in PDF without re-encoding. Highest quality. pdfimages -j "IN.pdf" "image_root_name" for f in *.pdf; do pdfimages -j "$f" "${f%.pdf}_img"; done
POPExtract Text Dumps text layer to .txt file. pdftotext -layout "IN.pdf" "OUT.txt" for f in *.pdf; do pdftotext -layout "$f" "${f%.pdf}.txt"; done
GREPSearch Inside PDFs Finds PDFs containing a specific word. pdfgrep -H "Invoice" "IN.pdf" pdfgrep -H "Valuation" *.pdf

4. Privacy & Metadata (Scrubbers)

Task / Goal Single File Command Batch Folder Loop
GSNuclear Scrub Rewrites PDF. 100% removal of history/metadata. gs -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -sOutputFile="clean.pdf" -c "[/Producer()/Author()/Title()/DOCINFO pdfmark" -f "IN.pdf" mkdir clean; for f in *.pdf; do gs -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -sOutputFile="clean/$f" -c "[/Producer()/Author()/Title()/DOCINFO pdfmark" -f "$f"; done
GSInject Title "Valuation" Forces Title tag update during rewrite. gs -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -sOutputFile="titled.pdf" -c "[/Title(Valuation)/DOCINFO pdfmark" -f "IN.pdf" mkdir titled; for f in *.pdf; do gs -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -sOutputFile="titled/$f" -c "[/Title(Valuation)/DOCINFO pdfmark" -f "$f"; done
EXIFRename from Title Files become "Title.pdf" exiftool '-filename<Title.pdf' "IN.pdf" exiftool '-filename<Title.pdf' -ext pdf .
EXIFRename from Date Files become "YYYY-MM-DD_filename.pdf" exiftool -d %Y-%m-%d '-filename<${CreateDate}_%f.%e' "IN.pdf" exiftool -d %Y-%m-%d '-filename<${CreateDate}_%f.%e' -ext pdf .

5. OCR (Text Recognition)

Task / Goal Single File Command Batch Folder Loop
OCRAdd Text Layer Standard processing. ocrmypdf "IN.pdf" "SEARCHABLE.pdf" for f in *.pdf; do ocrmypdf "$f" "ocr_$f"; done
OCRForce OCR / Redo Ignores existing (bad) text layer. ocrmypdf --force-ocr "IN.pdf" "REDO.pdf" for f in *.pdf; do ocrmypdf --force-ocr "$f" "redo_$f"; done
OCRDeskew & Clean Straightens pages before reading text. ocrmypdf --deskew --clean "IN.pdf" "CLEAN.pdf" for f in *.pdf; do ocrmypdf --deskew --clean "$f" "clean_$f"; done

Task / Goal Command / Trick
NETInstant File Transfer Host current folder on Wi-Fi. Access via PC browser at PhoneIP:8000. python -m http.server 8000
ZIPEncrypted Backup Zip folder with a password. zip -er secrets.zip my_folder/
FINDFind Large Files Locate PDFs larger than 10MB. find . -name "*.pdf" -size +10M
HASHFind Duplicates Compare files by content (MD5), not name. find . -type f -exec md5sum {} + | sort | uniq -w32 -d
IMWatermark "COPY" Add transparent text to center. for f in *.jpg; do magick "$f" -gravity center -pointsize 100 -fill "rgba(0,0,0,0.2)" -annotate 0 "COPY" "wm_$f"; done
IMContact Sheet Create a grid image of all PDFs (page 1). montage -density 150 -tile 3x0 -geometry 300x+5+5 -border 2 -label "%t" *.pdf[0] "overview.jpg"
