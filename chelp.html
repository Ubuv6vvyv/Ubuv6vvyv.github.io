Wayback Machine (CDX API) Queries

These commands query the Wayback Machine's *index* of archived URLs. They do not crawl the live site.

Goal Command (Click to copy)
Get All Unique URLs (Main Domain) curl -s "http://web.archive.org/cdx/search/cdx?url=example.com/*&output=text&fl=original&collapse=urlkey" | tee example.com_urls.txt
Get All Unique URLs (incl. Subdomains) curl -s "http://web.archive.org/cdx/search/cdx?url=*.example.com/*&output=text&fl=original&collapse=urlkey" | tee example.com_all_urls.txt
Filter: Only Successful URLs (200 OK) (incl. Subdomains) curl -s "http://web.archive.org/cdx/search/cdx?url=*.example.com/*&output=text&fl=original&collapse=urlkey&filter=statuscode:200"
Filter: Only PDFs (incl. Subdomains) curl -s "http://web.archive.org/cdx/search/cdx?url=*.example.com/*&output=text&fl=original&collapse=urlkey&filter=mimetype:application/pdf" | tee example.com_pdfs.txt
Filter: Only JavaScript Files (incl. Subdomains) curl -s "http://web.archive.org/cdx/search/cdx?url=*.example.com/*&output=text&fl=original&collapse=urlkey&filter=mimetype:application/javascript"
Filter: Only XML Files (e.g., Sitemaps) (incl. Subdomains) curl -s "http://web.archive.org/cdx/search/cdx?url=*.example.com/*&output=text&fl=original&collapse=urlkey&filter=mimetype:text/xml"
Filter: By Date (2023 Onwards) (incl. Subdomains) curl -s "http://web.archive.org/cdx/search/cdx?url=*.example.com/*&output=text&fl=original&collapse=urlkey&from=2023"

Live Crawling Tools

⚠️ Warning: Crawling a live site "as fast as possible" can get your IP banned or harm the server. Always check /robots.txt first and be respectful. These tools must be installed on your system.

Goal (Tool) Command (Click to copy)
Find Sitemap in `robots.txt` (curl) curl -s "https://example.com/robots.txt" | grep -i "Sitemap:" | awk '{print $2}'
Find All Links on a Single Page (curl) curl -s "https://example.com" | grep -Eo 'href="([^"]+)"' | cut -d'"' -f2 | tee example.com_page_links.txt
Faster "Spider" (Log All URLs) (wget) wget --spider -r -l 5 --wait=0.5 --random-wait -U "Mozilla/5.0" https://example.com -o example.com_crawl.log; cat example.com_crawl.log | grep -Eoi '(http|https)://[^ ]+' | sort -u | tee example.com_wget_urls.txt
List ONLY PDF Links (Recursive) (wget) wget --spider -r -l 5 --wait=0.5 --random-wait -A.pdf -U "Mozilla/5.0" https://example.com 2>&1 | grep '^--' | awk '{print $3}' | grep -i '\.pdf' | sort -u | tee example.com_pdf_links.txt
Download ONLY PDFs (Recursive) (wget) wget -r -l 5 --wait=0.5 --random-wait -A.pdf -U "Mozilla/5.0" https://example.com
Mirror Site (Faster but Polite) (wget) wget -m -k -p --wait=0.5 --random-wait -U "Mozilla/5.0" https://example.com
Fast/Deep Crawl (Log All URLs) (gospider) gospider -s "https://example.com" -c 25 -d 5 --include-subs --other-source --robots | tee example.com_gospider.txt
List ONLY PDF Links (Fast) (gospider) gospider -s "https://example.com" -c 25 -d 5 --include-subs --other-source --robots | grep -i '\.pdf' | sort -u | tee example.com_gospider_pdfs.txt
Find "Hidden" Links in JS (hakrawler) echo "https://example.com" | hakrawler -d 2 -scope subdomains | tee example.com_hakrawler.txt
